================================================================================
OUTPUT TABLE — BUILD INSTRUCTIONS
================================================================================
This document describes every feature of the interactive output table in
src/components/OutputPanel.tsx (the TableView component). Follow each step in
order and check off every "[ ]" item to ensure full parity with the original
implementation.

The table is rendered inside the OutputPanel, which is the bottom section of
the Playground page. The OutputPanel has a header with three view tabs
(Table, JSON, Document), a console bar, and a content area. The TableView
is shown when the "Table" tab is active.

================================================================================
SECTION 1 — DATA PREPARATION
================================================================================
Goal: Convert arbitrary execution results into a uniform table structure.

1.1  Define the TableData interface
     [ ] Create an interface with:
         - rows: Record<string, unknown>[]  (array of row objects)
         - keys: string[]                   (column header names)
         - isKeyValue: boolean              (true when source was a plain object)

1.2  Define the CellData interface
     [ ] Create an interface with:
         - column: string        (column header name)
         - content: string        (display text for popup)
         - contentForCopy: string (text used when copying to clipboard)
         - row: number            (zero-based row index)
         - col: number            (zero-based column index)

1.3  Implement prepareTableData(result)
     [ ] If result is a non-empty array of objects:
         - Extract keys from Object.keys(result[0])
         - Return { rows, keys, isKeyValue: false }
     [ ] If result is a non-null, non-array object:
         - Map Object.entries into rows of { Key, Value }
         - Return { rows, keys: ["Key", "Value"], isKeyValue: true }
     [ ] Otherwise return null (not suitable for table display)

1.4  Build the allCells array
     [ ] Iterate every row and every column key
     [ ] For each cell, call getCellContent(value) to get { content, contentForCopy }
     [ ] Push a CellData object into allCells with row/col indices

SECTION 2 — ROW SELECTION (CHECKBOXES)
================================================================================
Goal: Allow the user to select/deselect rows via checkboxes and click-to-select,
with shift-click range selection.

2.1  State
     [ ] selected: Set<number> — stores selected row indices (starts empty)
     [ ] lastSelectedRef: useRef<number | null> — tracks the last clicked row
         for shift-range selection

2.2  Reset selection on data change
     [ ] Add a useEffect that watches `data` and resets selected to new Set()
         and focusedCell to null — this ensures NO rows are pre-selected when
         new results arrive

2.3  Toggle a single row (toggleRow)
     [ ] If shiftKey is held AND lastSelectedRef is set AND differs from
         current row:
         - Compute start/end range
         - Determine target state (add or remove) from the current row's state
         - Loop from start to end, adding or removing each index
     [ ] Otherwise:
         - Toggle the single row in the Set
         - Update lastSelectedRef.current to the clicked row index

2.4  Toggle all rows (toggleAll)
     [ ] If all rows are selected, clear the Set (deselect all)
     [ ] Otherwise, select every row index (0 to rows.length - 1)

2.5  Header checkbox
     [ ] Render a checkbox in the sticky header row (left-most column)
     [ ] checked = (selected.size === data.rows.length && rows.length > 0)
     [ ] onChange calls toggleAll

2.6  Per-row checkbox
     [ ] Render a checkbox in each row's first cell (sticky left column)
     [ ] checked = selected.has(rowIdx)
     [ ] onChange is a no-op (selection handled by onClick)
     [ ] onClick stops propagation (so it doesn't trigger the row click handler)
         and calls toggleRow(rowIdx, e.shiftKey)

2.7  Row click selection
     [ ] Add onClick to each <tr>
     [ ] If the click target is NOT an INPUT or BUTTON, call toggleRow(rowIdx,
         e.shiftKey) — this lets the user click anywhere on the row to toggle

2.8  Visual feedback for selected rows
     [ ] If selected.has(rowIdx): apply bg-primary/15
     [ ] Otherwise alternate: even rows bg-table-bg, odd rows bg-table-stripe/60
     [ ] Hover state: hover:bg-primary/5

SECTION 8 — POPUP DRAGGING
================================================================================
Goal: Let the user drag the popup around the screen by its header.

8.1  Drag state
     [ ] dragRef: useRef<{ startX, startY, origX, origY } | null>
     [ ] didDragRef: useRef<boolean> — tracks whether an actual drag occurred
         (to distinguish drag from click on overlay)

8.2  handleDragStart (onMouseDown of header)
     [ ] preventDefault and stopPropagation
     [ ] Set didDragRef.current = false
     [ ] Find the .popup-container element via closest()
     [ ] Get its bounding rect (left, top)
     [ ] Store dragRef = { startX: e.clientX, startY: e.clientY,
         origX: rect.left, origY: rect.top }
     [ ] Set popupPos to { x: rect.left, y: rect.top } (switches to fixed
         positioning)

8.3  Mouse move handler (global, added via useEffect when popup is open)
     [ ] If dragRef.current is null, return (not dragging)
     [ ] Set didDragRef.current = true
     [ ] Compute dx = e.clientX - dragRef.startX, dy = e.clientY - dragRef.startY
     [ ] Update popupPos = { x: origX + dx, y: origY + dy }

8.4  Mouse up handler (global)
     [ ] Set dragRef.current = null (stop dragging)

8.5  handleOverlayClick (onClick of overlay)
     [ ] If didDragRef.current is false (no drag happened), close the popup
     [ ] Reset didDragRef.current = false
     [ ] This prevents the popup from closing immediately after a drag

SECTION 9 — KEYBOARD NAVIGATION (TABLE)
================================================================================
Goal: Let the user move a cell selector around the table using arrow keys and
open the preview popup with Enter.

9.1  State
     [ ] focusedCell: { row: number; col: number } | null
     [ ] tableRef: useRef<HTMLDivElement> — the scrollable table container

9.2  Table container setup
     [ ] tabIndex={0} so the div can receive focus and keyboard events
     [ ] onKeyDown={handleTableKeyDown}
     [ ] outline-none (no focus ring on the container itself)
     [ ] focus:ring-2 focus:ring-primary/40 (subtle ring when focused)

9.3  handleTableKeyDown logic
     [ ] If popupCell is open, return (let the popup's key handler take over)
     [ ] If key is not ArrowUp/Down/Left/Right/Enter, return
     [ ] preventDefault to stop page scrolling
     [ ] If no focusedCell yet: set to { row: 0, col: 0 } and return
     [ ] If Enter: find the cell at focusedCell, open the popup (set popupPos
         null, set popupCell)
     [ ] ArrowUp: row = Math.max(0, row - 1)
     [ ] ArrowDown: row = Math.min(rows.length - 1, row + 1)
     [ ] ArrowLeft: col = Math.max(0, col - 1)
     [ ] ArrowRight: col = Math.min(keys.length - 1, col + 1)
     [ ] Update focusedCell
     [ ] requestAnimationFrame: query the cell element by
         [data-cell="${row}-${col}"] and call scrollIntoView({ block:
         "nearest", inline: "nearest" }) to keep it visible

9.4  Visual focus indicator
     [ ] Each <td> checks: isFocused = focusedCell?.row === rowIdx &&
         focusedCell?.col === colIdx
     [ ] If focused: add "ring-2 ring-primary ring-inset bg-primary/10"
